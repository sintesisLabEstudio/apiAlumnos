Ejercicios:
Desarrolle dos aplicaciones, donde una de ellas contenga una API la cual posea la lógica para el ingreso y consulta de datos y por último una aplicación Android.

Ejercicio:
Genere una API en la cual pueda ingresar Alumnos, Asignaturas y Notas, donde la nota debe tener un total de 3 por alumno y asignatura (N_NOTA sirve para controlar cual es la nota que se está ingresando, de 1 a 3, lo cual es un valor fijo).
Debe poder listar los alumnos junto con su nota y asignatura de la siguiente manera:
●	COD_ALUMNO
●	NOMBRE_COMPLETO
●	NOM_ASIGNATURA
●	N_NOTA_1
●	NOTA_1
●	N_NOTA2
●	NOTA_2
●	N_NOTA_3
●	NOTA_3
●	PROMEDIO
Si una nota o las 3 no se encuentran, no debe mostrar el valor en el campo, solo lo que está disponible, y el PROMEDIO se calcula sólo si están las 3 notas ingresadas.
Se pueden editar las notas seleccionando al alumno y el número de nota a editar.
La nota mínima es 1.0 y máxima 7.0
La inserción de notas, alumnos y asignaturas deberán ser realizadas por la aplicación Android consumiendo la API creada.
